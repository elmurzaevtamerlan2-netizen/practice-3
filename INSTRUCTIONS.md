# RoomBook — практическая №3

Консольная промежуточная версия системы бронирования аудиторий. Демонстрация создаёт заявку, подтверждает её, проверяет отказ при пересечении интервалов и выводит CSV со списком заявок. Данные хранятся в памяти процесса, уведомления выводятся в консоль. Веб-интерфейс, SSO и постоянное хранилище относятся к полной версии из SRS.

## Сборка и запуск

Требуются JDK 17+ и Apache Maven 3.9+.

```sh
mvn clean package
java -jar target/roombook-0.1.0.jar
```

Ожидаемый вывод содержит статусы PENDING и CONFIRMED для A-301, сообщение об отклонённом конфликте и CSV из одной строки данных.

Apache Commons CSV 1.11.0 форматирует выгрузку и экранирует значения. Maven Shade Plugin упаковывает зависимости в исполняемый JAR.

## Пакеты

- `domain` — бронь и интервал времени.
- `application` — создание и подтверждение заявок, предотвращение конфликтов.
- `report` — вывод CSV.
